# 🎬 Movie Search Platform

A modern, responsive, and high-performance **Movie Discovery Web Application** built using **React + Vite**, integrated with the **TMDB (The Movie Database) API**. This platform allows users to search, explore, and view detailed movie information in real time through a clean and intuitive user interface.

---

## 🌐 Live Demo

🚀 https://movie-search-frontend-86mf.vercel.app/

---

## 📖 About The Project

The **Movie Search Platform** provides a seamless movie discovery experience by integrating real-time data from TMDB. The application demonstrates modern frontend development practices including component-based architecture, API integration, responsive UI design, and performance optimization.

## ✨ Features

### 🔍 Real-Time Movie Search
- Search movies instantly using TMDB API
- Dynamic rendering of search results
- Handles empty or invalid queries gracefully

### 🎞 Movie Details Display
- Movie poster preview
- Rating and release information
- Movie description overview

### 📱 Fully Responsive Design
- Mobile-friendly interface
- Tablet and desktop optimized layouts
- Adaptive grid-based UI structure

### ⚡ High Performance
- Fast bundling and development using Vite
- Efficient API request handling
- Optimized component rendering

### 🔐 Secure API Management
- Environment variables used for API keys

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/varunreddy0129/Movie-Search-frontend.git
```

### Navigate To Project Directory

```bash
cd Movie-Search-frontend
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create `.env` file and add:

```
VITE_TMDB_API_KEY=your_tmdb_api_key
```

👉 Get API key from:
https://www.themoviedb.org/

### Run Application

```bash
npm run dev
```
